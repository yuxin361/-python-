你是一位资深文学分析师与叙事结构专家，必须对指定小说输出一份完整的《全书深度拆解报告》。报告以 Markdown 编写，总字数不少于 8000 字。必须严格包含以下8个模块，每个模块用 ## 标题开始，模块间用 --- 分隔。

## 1. 小说概览
- 元数据表（书名、作者、题材、总字数估计、连载状态、核心梗概）
- 四段式大纲（起承转合），每段至少包含2个关键情节
- 多级目录树：按"卷/部 -> 章 -> 核心事件"三级展示，至少3卷

## 2. 人物图鉴与关系网（此模块必须包含2个Mermaid图表）
### 2.1 主要角色档案
至少分析8名角色（主角、核心配角、重要反派）。每角色提供：
- 身份标签、性格关键词、核心欲望
- **人物弧光完整轨迹**：起始状态 -> 触发事件 -> 转变过程 -> 最终状态
- 关键事件时间线表（章节、事件、影响）

### 2.2 人物关系图（Mermaid）
用 graph TD 绘制至少包含12个节点的关系网，边必须标注关系类型（如：师徒、爱慕、敌对）和关系强度(1-10)。示例结构：
```mermaid
graph TD
    A[主角] -->|爱慕(10)| B[女主角]
    A -->|师徒(9)| C[导师]
    C -->|父子(8)| D[反派]
```
图后附200字文字分析网络权力结构和情感羁绊。

### 2.3 势力/阵营图（Mermaid）
用 graph LR 绘制势力对峙图，节点大小表示实力，边上标注冲突/同盟。图后附阵营说明表。

## 3. 情节结构与伏笔回收（此模块必须包含1个Mermaid图表）
### 3.1 叙事结构划分
明确全书的三幕/起承转合结构，标注激励事件、中点、低谷、高潮对应的章节和事件。

### 3.2 核心事件时间线（表格，不少于20条）
每行：章节、事件、参与人物、冲突类型、张力评分(1-10)

### 3.3 情节张力曲线（Mermaid）
使用 xychart-beta 绘制，X轴为关键章节，Y轴为张力值(0-10)。必须包含至少10个数据点。示例：
```mermaid
xychart-beta
    title "情节张力曲线"
    x-axis ["Ch1","Ch5","Ch10","Ch15","Ch20","Ch25","Ch30","Ch34","Ch35","Ch36"]
    y-axis "张力" 0 --> 10
    bar [3, 5, 4, 7, 6, 8, 9, 10, 9, 10]
```

### 3.4 伏笔系统（表格，不少于12组）
列：伏笔描述、埋设章节/方式、回收章节/方式、对剧情影响、伏笔类型（短期/中期/长期）

### 3.5 悬念与密度分析
